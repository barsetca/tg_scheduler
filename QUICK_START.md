# Быстрый старт

## Проблема: Бот не запускается после перезагрузки компьютера

### Причина
После создания нового виртуального окружения (`python3 -m venv venv`) зависимости не устанавливаются автоматически. Нужно выполнить `pip install -r requirements.txt`.

### Решение

**Вариант 1: Автоматическая установка (рекомендуется)**

```bash
./setup.sh
```

Этот скрипт автоматически:
- Проверит версию Python
- Создаст виртуальное окружение (если его нет)
- Установит все зависимости
- Готово к запуску!

**Вариант 2: Ручная установка**

```bash
# 1. Создайте виртуальное окружение (если его нет)
python3 -m venv venv

# 2. Активируйте его
source venv/bin/activate

# 3. УСТАНОВИТЕ ЗАВИСИМОСТИ (эt то важно!)
pip install -r requirements.txt
```

## Запуск бота

**Автоматический запуск:**
```bash
./run.sh
```

**Ручной запуск:**
```bash
source venv/bin/activate
python3 main.py
```

## Остановка бота

**Автоматическая остановка:**
```bash
./stop.sh
```

**Ручная остановка:**
```bash
# Найти процесс
ps aux | grep "python.*main.py"

# Остановить процесс (замените PID на реальный номер процесса)
kill <PID>
```

**Если бот не останавливается:**
```bash
# Принудительная остановка
kill -9 <PID>
```

## Восстановление удаленных файлов

Если файлы были удалены из git (`.gitignore`, `__init__.py` и т.д.):

```bash
git restore .gitignore
git restore handlers/__init__.py
git restore middleware/__init__.py
git restore services/__init__.py
git restore utils/__init__.py
git restore pyrightconfig.json
```

Или восстановите все файлы сразу:
```bash
git restore .
```

## Важные напоминания

1. **Всегда устанавливайте зависимости** после создания нового `venv`
2. **Активируйте виртуальное окружение** перед запуском (`source venv/bin/activate`)
3. **Проверьте наличие `.env` файла** с настройками бота
