# Telegram Task Manager Bot

Telegram бот для управления ежедневными задачами с напоминаниями и периодичностью.

## 🚀 Возможности

- ✅ Создание, редактирование и удаление задач
- ⏰ Напоминания с возможностью откладывания
- 🔄 Периодические задачи (каждый час, день, неделю, месяц, год)
- 📋 Просмотр задач на сегодня и по дате
- 📊 Фильтрация задач (все, выполненные, просроченные)
- 💾 Хранение данных в SQLite

## 📋 Требования

- Python 3.10+
- Telegram Bot Token (получить у [@BotFather](https://t.me/BotFather))

## 🔧 Установка

1. Клонируйте репозиторий или скачайте файлы проекта

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```

4. Отредактируйте `.env` и укажите:
   - `BOT_TOKEN` - токен вашего бота от BotFather
   - `ADMIN_ID` - ваш Telegram ID (опционально)
   - `DATABASE_PATH` - путь к базе данных (по умолчанию `./data/tasks.db`)
   - `TIMEZONE` - часовой пояс (по умолчанию `Europe/Moscow`)
   - `LOG_LEVEL` - уровень логирования (по умолчанию `INFO`)

## 🏃 Запуск

```bash
python main.py
```

Бот автоматически:
- Создаст базу данных и таблицы при первом запуске
- Запустит планировщик для проверки напоминаний
- Начнет обрабатывать команды и сообщения

## 📖 Использование

### Основные команды

- `/start` - Главное меню
- `/newtask` - Создать новую задачу
- `/tasksdate` - Просмотр задач по дате
- `/help` - Справка

### Создание задачи

1. Нажмите "➕ Новая задача" или отправьте `/newtask`
2. Введите описание задачи
3. Выберите дату (по умолчанию - сегодня)
4. Укажите время (опционально, формат HH:MM)
5. Выберите время напоминания (0, 5, 15, 30, 60 минут)
6. Выберите периодичность (если нужна)

### Напоминания

Когда приходит время напоминания, бот отправляет сообщение с тремя кнопками:
- ⏰ **Отложить** - отложить напоминание на указанное количество минут
- ✅ **Завершить** - отметить задачу как выполненную
- 🗑️ **Удалить** - удалить задачу

### Периодические задачи

После выполнения периодической задачи автоматически создается следующая:
- **Каждый час** - следующая задача через час
- **Каждый день** - следующая задача на завтра
- **Каждую неделю** - следующая задача через неделю
- **Каждый месяц** - следующая задача через месяц
- **Каждый год** - следующая задача через год

## 🔒 Безопасность и изоляция пользователей

**Полная изоляция данных:**
- Каждый пользователь работает независимо - все данные изолированы по `user_id`
- Пользователи видят и могут редактировать только свои задачи
- Все операции с задачами и напоминаниями проверяют принадлежность пользователю
- FSM (состояния диалога) автоматически изолированы по пользователям в aiogram
- SQL-запросы используют параметризацию (защита от SQL-injection)
- Чувствительные данные не логируются

**Многопользовательская работа:**
- Бот поддерживает одновременную работу неограниченного количества пользователей
- Каждый пользователь имеет свой независимый набор задач и напоминаний
- Напоминания отправляются каждому пользователю индивидуально
- Нет конфликтов между данными разных пользователей

## 🐛 Устранение неполадок

**Бот не запускается:**
- Проверьте, что `BOT_TOKEN` указан в `.env`
- Убедитесь, что все зависимости установлены
- Проверьте логи на наличие ошибок

**Напоминания не приходят:**
- Убедитесь, что у задачи указано время
- Проверьте, что планировщик запущен (должно быть в логах)
- Проверьте часовой пояс в настройках

**Ошибки базы данных:**
- Убедитесь, что директория для БД существует и доступна для записи
- При необходимости удалите старую БД и перезапустите бота
